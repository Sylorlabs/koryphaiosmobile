Run launch/pair, chat/project/model selection, send/stream/stop, attention/review, attachment, settings/control, reconnect, background/foreground and lock/unlock. Capture portrait/landscape, keyboard up/down and accessibility text. Tablets also require hardware keyboard, split screen and resizing while typing/streaming.

Pass means controls remain reachable, drafts survive, machine/chat selection stays correct, host actions are confirmed and recovery does not replay mutations. A web viewport is supplemental responsive evidence only.
